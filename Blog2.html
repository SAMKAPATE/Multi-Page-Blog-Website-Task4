JavaScript DOM Manipulation for Beginners

June 8, 2026 6 min read DevDiary Team
⚡

The DOM (Document Object Model) is the key to making websites interactive. When you click a button, submit a form, or see a dropdown menu — that's all JavaScript manipulating the DOM. Let's learn how it works!

What is the DOM?

The DOM is a tree-like representation of your HTML. Every HTML tag becomes a "node" in the tree. JavaScript can read, change, add, or delete any of these nodes in real time.

Selecting Elements

// By ID const title = document.getElementById('myTitle'); // By class const cards = document.querySelectorAll('.card'); // By tag const buttons = document.querySelectorAll('button');

Changing Content & Style

// Change text title.textContent = 'New Title!'; // Change style title.style.color = '#00f5c4'; title.style.fontSize = '3rem'; // Add/remove CSS class title.classList.add('active'); title.classList.remove('hidden'); title.classList.toggle('dark');

Event Listeners

Event listeners let you run code when something happens — a click, hover, scroll, or keypress.

const btn = document.getElementById('myBtn'); btn.addEventListener('click', function() { alert('Button clicked!'); }); // Scroll event window.addEventListener('scroll', () => { if (window.scrollY > 50) { navbar.classList.add('scrolled'); } });

Pro Tip: Use addEventListener instead of inline onclick handlers. It keeps your HTML clean and your JS organized!

Creating & Removing Elements

// Create new element const newDiv = document.createElement('div'); newDiv.textContent = 'I was created by JS!'; newDiv.classList.add('card'); // Add to page document.body.appendChild(newDiv); // Remove element newDiv.remove();

Key Things to Remember

  • DOM manipulation runs in the browser — no server needed
  • Always select elements before trying to change them
  • Use console.log() to debug your code
  • The DOM updates instantly — users see changes right away

Now you know the basics of DOM manipulation! Practice by building a to-do list app, a dark mode toggle, or a form validator. These are classic beginner JavaScript projects. 🚀
