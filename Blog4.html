How to Host Your Website for Free on GitHub Pages

June 22, 2026 4 min read DevDiary Team
🚀

You've built your portfolio or blog website — now it's time to show it to the world! GitHub Pages is the easiest and most popular free hosting platform for static websites. Let's deploy your site in under 10 minutes!

What is GitHub Pages?

GitHub Pages is a free hosting service by GitHub. It takes your HTML, CSS, and JavaScript files from a GitHub repository and serves them as a live website. No server setup, no cost — just push your code and it's live!

Perfect for: Personal portfolios, blog websites, project pages, internship task submissions — anything built with HTML, CSS and JavaScript!

Step-by-Step Guide

1

Create a GitHub Account

Go to github.com and sign up for a free account if you don't have one already.

2

Create a New Repository

Click the "+" icon → "New repository". Name it your-username.github.io for a personal site, or any name for a project site.

3

Upload Your Files

Click "Add file" → "Upload files". Drag and drop your index.html, CSS, JS files. Make sure index.html is in the root folder!

4

Enable GitHub Pages

Go to Settings → Pages → Source → Select "main" branch → Save. GitHub will give you a live URL in seconds!

5

Your Site is Live! 🎉

Your website will be live at https://your-username.github.io/repo-name. Share it anywhere!

Using Git Commands (Optional)

# Initialize git in your project folder git init git add . git commit -m "first commit" # Connect to GitHub repo git remote add origin https://github.com/username/repo.git # Push to GitHub git push -u origin main

Tips for a Better GitHub Profile

  • Always add a README.md to explain your project
  • Use clear commit messages — "add hero section" not just "update"
  • Pin your best repositories on your profile
  • Keep your profile photo and bio updated

That's it! Your website is now live on the internet for anyone to see. Share your GitHub Pages link on LinkedIn, add it to your resume, and include it in your internship submissions. 🚀
