Getting Started with HTML & CSS — A Beginner's Complete Guide

June 1, 2026 8 min read DevDiary Team
🌐

HTML and CSS are the foundation of every single website on the internet. Whether you want to become a professional developer or just build your own blog, learning HTML and CSS is the very first step. In this guide, we'll cover everything a complete beginner needs to know.

What is HTML?

HTML stands for HyperText Markup Language. It's the skeleton of every webpage — it defines the structure and content. Think of it like the walls and rooms of a house.

<!DOCTYPE html> <html> <head> <title>My First Page</title> </head> <body> <h1>Hello World!</h1> <p>This is my first webpage.</p> </body> </html>

What is CSS?

CSS stands for Cascading Style Sheets. It's the styling layer — it makes your HTML look beautiful. Think of CSS as the paint, furniture, and decorations of the house.

body { background-color: #080a0f; color: #eaeaf5; font-family: 'DM Sans', sans-serif; } h1 { font-size: 3rem; color: #00f5c4; }

Key HTML Tags You Must Know

  • <h1> to <h6> — Headings (h1 is biggest)
  • <p> — Paragraph text
  • <a> — Links (anchor tags)
  • <img> — Images
  • <div> — Container / block element
  • <section> — Semantic section of a page
  • <nav> — Navigation bar

Pro Tip: Always use semantic HTML tags like <header>, <main>, <footer> instead of just <div> for everything. It makes your code cleaner and better for SEO.

CSS Box Model

Every HTML element is a box. The CSS Box Model describes how the element's size is calculated — content, padding, border, and margin all play a role.

Responsive Design

Modern websites must look good on all screen sizes. Use CSS media queries to adapt your layout for mobile devices.

@media (max-width: 768px) { .hero h1 { font-size: 2rem; } .nav-links { display: none; } }

What to Learn Next?

  • CSS Flexbox and Grid for layouts
  • JavaScript for interactivity
  • Google Fonts and Font Awesome for styling
  • GitHub Pages for hosting your site for free

That's it! You now have a solid foundation in HTML and CSS. The best way to learn is to keep building — start with a simple page and keep improving it every day. 🚀
